## Student 1: [Brenna Pratt] (`bepratt`)

- **The component I "owned" and that I summarize here is best described as** the regression analysis addressing RQ1, data merging methodology, and descriptive statistics for communication apprehension and transportation usage variables.

- **You can find this contribution in a file called** `index.qmd` **at lines** 27–29 (RQ1 hypotheses), 47–49 (data merging), 55–141 (descriptive statistics), and 145–186 (regression analysis results). [Permalink to index.qmd](https://github.com/bepratt/psych755-summer-project/blob/main/index.qmd#L27-L29)
- **Owning this component means** I designed the regression analysis approach to test the correlation between group communication apprehension and public transportation usage, implemented the data merging strategy combining our datasets, constructed the communication apprehension composite score from 12 survey items with appropriate reverse coding (Q2, Q4, Q6, Q14, Q16, Q17), and interpreted the significant negative relationship (slope: -0.4147, R²: 0.108, p < 0.001).
- **The commits or PRs that are most relevant are** *[pull request 23, 25 and 26.]*
- **The portion of the data science process that this effort contributes to is** Select + Apply — choosing linear regression to test the correlation hypothesis and applying it with proper variable construction, plus Interpret for the data merging and coding decisions that ensured the analysis used appropriately processed survey data.
